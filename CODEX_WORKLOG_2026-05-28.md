# SupoClip: Worklog (2026-05-28)

## Что было сделано

1. Развернут и проверен локальный запуск проекта (frontend/backend/worker).
2. Добавлены/проверены переменные окружения для внешних API в `.env` (без публикации ключей в коде/логах).
3. Исправлен зависающий прогресс:
   - этап `30%` (транскрипция) — обновлена конфигурация AssemblyAI под актуальный параметр `speech_models`;
   - этап `10%` (скачивание) — улучшена загрузка YouTube в `yt-dlp` (прогрессивный mp4), чтобы снизить размер и риски по диску.

   - выявлено, что стандартный `ffmpeg` не содержал нужных фильтров (`ass/subtitles/drawtext`);

   - добавлен fallback: если прожиг субтитров падает, клип все равно сохраняется.
5. Улучшено авто-кадрирование по говорящему:
   - включено speaker-aware рефрейминг поведение для обычного `vertical`;
   - ослаблен слишком строгий фильтр по количеству scene cuts;
   - расширен face detection: добавлен `haarcascade_profileface` и зеркальный проход для профильных лиц.
6. Перезапущены backend/worker с актуальными переменными и проверен health-check.
7. Проведен контрольный прогон задачи, подтверждено:
   - клипы генерируются;
   - субтитры прожигаются;
   - кадрирование по лицу стало стабильнее на проблемных фрагментах.
